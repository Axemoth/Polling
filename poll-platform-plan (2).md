# Poll Platform — Full Project Plan

## Overview

A full-stack platform where authenticated users create polls, share them via public links, collect responses, and view live analytics. Built as a single GitHub monorepo with a React frontend and Express backend.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React (Vite), React Router v6, Axios, Socket.io-client, Recharts |
| Backend | Node.js, Express |
| ORM | Drizzle ORM + drizzle-kit |
| Database | PostgreSQL |
| Auth | OIDC SSO via `openid-client` → `https://oidc.axemoth.com/` |
| Session | `express-session` + `connect-pg-simple` |
| Real-time | Socket.io |
| Scheduler | `node-cron` |
| Validation | `zod` (backend) + React Hook Form (frontend) |
| Slug generation | `nanoid` |

## Database Schema (Drizzle ORM)

All tables live in `server/db/schema.js`.

```js
import {
  pgTable, uuid, text, boolean,
  timestamp, integer, index
} from 'drizzle-orm/pg-core';
import { relations } from 'drizzle-orm';

// ─── users ───────────────────────────────────────────────────────────────────
// No password_hash — identity comes entirely from the OIDC provider.
// `sub` is the stable unique identifier from the id_token.

export const users = pgTable('users', {
  id:        uuid('id').primaryKey().defaultRandom(),
  sub:       text('sub').notNull().unique(),   // OIDC subject claim
  email:     text('email'),
  name:      text('name'),
  createdAt: timestamp('created_at').defaultNow().notNull(),
});

// ─── polls ───────────────────────────────────────────────────────────────────
// public_slug drives the shareable URL: /poll/:slug
// is_active is set to false when expires_at passes (by cron job).
// is_published allows anyone visiting the slug to see results.
// is_anonymous controls whether respondent_id is stored on responses.

export const polls = pgTable('polls', {
  id:          uuid('id').primaryKey().defaultRandom(),
  creatorId:   uuid('creator_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  title:       text('title').notNull(),
  description: text('description'),
  publicSlug:  text('public_slug').notNull().unique(),
  isAnonymous: boolean('is_anonymous').notNull().default(false),
  isPublished: boolean('is_published').notNull().default(false),
  isActive:    boolean('is_active').notNull().default(true),
  expiresAt:   timestamp('expires_at'),           // null = never expires
  createdAt:   timestamp('created_at').defaultNow().notNull(),
}, (t) => ({
  slugIdx:    index('polls_slug_idx').on(t.publicSlug),
  creatorIdx: index('polls_creator_idx').on(t.creatorId),
}));

// ─── questions ───────────────────────────────────────────────────────────────
// order_index determines display order on the form.
// is_mandatory is enforced on both frontend and backend.

export const questions = pgTable('questions', {
  id:          uuid('id').primaryKey().defaultRandom(),
  pollId:      uuid('poll_id').notNull().references(() => polls.id, { onDelete: 'cascade' }),
  text:        text('text').notNull(),
  orderIndex:  integer('order_index').notNull().default(0),
  isMandatory: boolean('is_mandatory').notNull().default(true),
});

// ─── options ─────────────────────────────────────────────────────────────────
// Single-choice only: each question has 2–n options.
// Analytics queries do GROUP BY selected_option_id on the answers table.

export const options = pgTable('options', {
  id:         uuid('id').primaryKey().defaultRandom(),
  questionId: uuid('question_id').notNull().references(() => questions.id, { onDelete: 'cascade' }),
  text:       text('text').notNull(),
  orderIndex: integer('order_index').notNull().default(0),
});

// ─── responses ───────────────────────────────────────────────────────────────
// One response row = one poll submission.
//
// Authenticated mode:   respondent_id = users.id,  session_token = null
// Anonymous mode:       respondent_id = null,       session_token = nanoid()
//   The client stores session_token in localStorage and sends it on submit.
//   Backend checks uniqueness of (poll_id, session_token) to block re-submissions
//   without identifying the user.

export const responses = pgTable('responses', {
  id:           uuid('id').primaryKey().defaultRandom(),
  pollId:       uuid('poll_id').notNull().references(() => polls.id, { onDelete: 'cascade' }),
  respondentId: uuid('respondent_id').references(() => users.id, { onDelete: 'set null' }),
  sessionToken: text('session_token'),            // used for anonymous mode
  submittedAt:  timestamp('submitted_at').defaultNow().notNull(),
}, (t) => ({
  pollIdx: index('responses_poll_idx').on(t.pollId),
  anonIdx: index('responses_anon_idx').on(t.pollId, t.sessionToken),
}));

// ─── answers ─────────────────────────────────────────────────────────────────
// One answer row per question in a response.
// For optional questions left blank, no row is created.

export const answers = pgTable('answers', {
  id:               uuid('id').primaryKey().defaultRandom(),
  responseId:       uuid('response_id').notNull().references(() => responses.id, { onDelete: 'cascade' }),
  questionId:       uuid('question_id').notNull().references(() => questions.id, { onDelete: 'cascade' }),
  selectedOptionId: uuid('selected_option_id').notNull().references(() => options.id),
});

// ─── Drizzle relations (for join helpers) ────────────────────────────────────

export const usersRelations = relations(users, ({ many }) => ({
  polls:     many(polls),
  responses: many(responses),
}));

export const pollsRelations = relations(polls, ({ one, many }) => ({
  creator:   one(users,     { fields: [polls.creatorId],   references: [users.id] }),
  questions: many(questions),
  responses: many(responses),
}));

export const questionsRelations = relations(questions, ({ one, many }) => ({
  poll:    one(polls,   { fields: [questions.pollId], references: [polls.id] }),
  options: many(options),
  answers: many(answers),
}));

export const optionsRelations = relations(options, ({ one, many }) => ({
  question: one(questions, { fields: [options.questionId], references: [questions.id] }),
  answers:  many(answers),
}));

export const responsesRelations = relations(responses, ({ one, many }) => ({
  poll:       one(polls,  { fields: [responses.pollId],       references: [polls.id] }),
  respondent: one(users,  { fields: [responses.respondentId], references: [users.id] }),
  answers:    many(answers),
}));

export const answersRelations = relations(answers, ({ one }) => ({
  response:       one(responses, { fields: [answers.responseId],       references: [responses.id] }),
  question:       one(questions, { fields: [answers.questionId],        references: [questions.id] }),
  selectedOption: one(options,   { fields: [answers.selectedOptionId],  references: [options.id] }),
}));
```

## OIDC Authentication

### Provider setup — `server/lib/oidc.js`

```js
import { Issuer, generators } from 'openid-client';

let oidcClient;

export async function initOidc() {
  const issuer = await Issuer.discover('https://oidc.axemoth.com/');
  oidcClient = new issuer.Client({
    client_id:      process.env.OIDC_CLIENT_ID,
    client_secret:  process.env.OIDC_CLIENT_SECRET,
    redirect_uris:  [process.env.OIDC_REDIRECT_URI],
    response_types: ['code'],
  });
}

export function getOidcClient() {
  return oidcClient;
}

export { generators };
```

Call `await initOidc()` before `server.listen()` in `server.js`.

### Auth routes — `server/routes/auth.js`

```js
import { Router } from 'express';
import { getOidcClient, generators } from '../lib/oidc.js';
import { db } from '../db/index.js';
import { users } from '../db/schema.js';
import { eq } from 'drizzle-orm';

const router = Router();

// Step 1 — redirect user to OIDC provider
router.get('/login', (req, res) => {
  const client = getOidcClient();
  const state  = generators.state();
  const nonce  = generators.nonce();

  req.session.oidcState = state;
  req.session.oidcNonce = nonce;

  const url = client.authorizationUrl({
    scope: 'openid email profile',
    state,
    nonce,
  });

  res.redirect(url);
});

// Step 2 — OIDC provider redirects back with ?code=…&state=…
router.get('/callback', async (req, res) => {
  const client   = getOidcClient();
  const params   = client.callbackParams(req);

  const tokenSet = await client.callback(
    process.env.OIDC_REDIRECT_URI,
    params,
    { state: req.session.oidcState, nonce: req.session.oidcNonce }
  );

  const claims = tokenSet.claims();   // decoded id_token payload

  // Upsert user by stable `sub` identifier
  const existing = await db.select().from(users).where(eq(users.sub, claims.sub));
  let user = existing[0];

  if (!user) {
    const [created] = await db.insert(users).values({
      sub:   claims.sub,
      email: claims.email,
      name:  claims.name,
    }).returning();
    user = created;
  }

  req.session.userId   = user.id;
  req.session.userName = user.name;
  delete req.session.oidcState;
  delete req.session.oidcNonce;

  res.redirect('/dashboard');
});

// Logout — clear session
router.get('/logout', (req, res) => {
  req.session.destroy(() => res.redirect('/'));
});

export default router;
```

### Auth middleware — `server/middleware/requireSession.js`

```js
export function requireSession(req, res, next) {
  if (!req.session.userId) {
    return res.status(401).json({ error: 'Unauthenticated' });
  }
  next();
}
```

### Poll owner guard — `server/middleware/requirePollOwner.js`

```js
import { db } from '../db/index.js';
import { polls } from '../db/schema.js';
import { eq } from 'drizzle-orm';

export async function requirePollOwner(req, res, next) {
  const [poll] = await db.select().from(polls).where(eq(polls.id, req.params.id));
  if (!poll) return res.status(404).json({ error: 'Poll not found' });
  if (poll.creatorId !== req.session.userId) {
    return res.status(403).json({ error: 'Forbidden' });
  }
  req.poll = poll;   // attach for downstream handlers
  next();
}
```

**Example create handler:**

```js
import { Router } from 'express';
import { db } from '../db/index.js';
import { polls, questions, options } from '../db/schema.js';
import { requireSession } from '../middleware/requireSession.js';
import { generateSlug } from '../lib/slug.js';

const router = Router();

router.post('/', requireSession, async (req, res) => {
  const { title, description, isAnonymous, expiresAt, questions: qs } = req.body;

  await db.transaction(async (tx) => {
    const slug = generateSlug();

    const [poll] = await tx.insert(polls).values({
      creatorId:   req.session.userId,
      title,
      description,
      publicSlug:  slug,
      isAnonymous: isAnonymous ?? false,
      expiresAt:   expiresAt ? new Date(expiresAt) : null,
    }).returning();

    for (let i = 0; i < qs.length; i++) {
      const [question] = await tx.insert(questions).values({
        pollId:      poll.id,
        text:        qs[i].text,
        orderIndex:  i,
        isMandatory: qs[i].isMandatory ?? true,
      }).returning();

      const optionRows = qs[i].options.map((text, j) => ({
        questionId: question.id,
        text,
        orderIndex: j,
      }));

      await tx.insert(options).values(optionRows);
    }

    res.json({ pollId: poll.id, publicSlug: slug });
  });
});

export default router;
```

### Responses — `server/routes/responses.js`


**Submit response request body:**

```json
{
  "sessionToken": "anon-abc123",
  "answers": [
    { "questionId": "uuid-q1", "selectedOptionId": "uuid-opt2" },
    { "questionId": "uuid-q2", "selectedOptionId": "uuid-opt5" }
  ]
}
```

**Backend validation steps (in order):**

1. Look up poll by slug — 404 if not found.
2. Check `is_active === true` — 403 if inactive.
3. Check `expires_at` server-side — 403 if past (catches cron race window).
4. If `is_anonymous === false`, require `req.session.userId` — 401 if missing.
5. Duplicate check:
   - Authenticated: `WHERE poll_id = ? AND respondent_id = ?`
   - Anonymous: `WHERE poll_id = ? AND session_token = ?`
   - Return 409 if already submitted.
6. Mandatory check: for each question where `is_mandatory = true`, confirm a matching entry exists in submitted answers — 400 with missing question IDs if not.
7. Insert `responses` row then all `answers` rows in a transaction.
8. After commit: fetch updated analytics and emit `live_update` via Socket.io.

```js
import { Router } from 'express';
import { db } from '../db/index.js';
import { polls, questions, responses, answers } from '../db/schema.js';
import { eq, and } from 'drizzle-orm';
import { getAnalytics } from './analytics.js';

const router = Router();

router.post('/:slug/respond', async (req, res) => {
  const { sessionToken, answers: submitted } = req.body;

  // 1. Find poll
  const [poll] = await db.select().from(polls).where(eq(polls.publicSlug, req.params.slug));
  if (!poll) return res.status(404).json({ error: 'Poll not found' });

  // 2 & 3. Active + expiry checks
  if (!poll.isActive) return res.status(403).json({ error: 'Poll is closed' });
  if (poll.expiresAt && new Date() > poll.expiresAt) {
    return res.status(403).json({ error: 'Poll has expired' });
  }

  // 4. Auth check for non-anonymous polls
  if (!poll.isAnonymous && !req.session.userId) {
    return res.status(401).json({ error: 'Login required to respond to this poll' });
  }

  // 5. Duplicate check
  const dupWhere = poll.isAnonymous
    ? and(eq(responses.pollId, poll.id), eq(responses.sessionToken, sessionToken))
    : and(eq(responses.pollId, poll.id), eq(responses.respondentId, req.session.userId));

  const [dup] = await db.select().from(responses).where(dupWhere);
  if (dup) return res.status(409).json({ error: 'Already submitted' });

  // 6. Mandatory question check
  const pollQuestions = await db.select().from(questions).where(eq(questions.pollId, poll.id));
  const submittedIds  = new Set(submitted.map(a => a.questionId));
  const missing       = pollQuestions
    .filter(q => q.isMandatory && !submittedIds.has(q.id))
    .map(q => q.id);

  if (missing.length > 0) {
    return res.status(400).json({ error: 'Missing mandatory questions', missing });
  }

  // 7. Save in transaction
  await db.transaction(async (tx) => {
    const [response] = await tx.insert(responses).values({
      pollId:       poll.id,
      respondentId: poll.isAnonymous ? null : req.session.userId,
      sessionToken: poll.isAnonymous ? sessionToken : null,
    }).returning();

    const answerRows = submitted.map(a => ({
      responseId:       response.id,
      questionId:       a.questionId,
      selectedOptionId: a.selectedOptionId,
    }));

    await tx.insert(answers).values(answerRows);
  });

  // 8. Emit live update
  const stats = await getAnalytics(poll.id);
  req.app.locals.io.to(poll.id).emit('live_update', stats);

  res.json({ success: true });
});

export default router;
```

### Analytics — `server/routes/analytics.js`

```
GET /api/polls/:id/analytics       requireSession + owner
GET /api/polls/:slug/results       public (only if is_published = true)
```

**Shared analytics helper + routes:**

```js
import { Router } from 'express';
import { db } from '../db/index.js';
import { questions, options, answers, responses, polls } from '../db/schema.js';
import { eq, sql } from 'drizzle-orm';
import { requireSession } from '../middleware/requireSession.js';
import { requirePollOwner } from '../middleware/requirePollOwner.js';

// Single SQL round-trip — returns option counts per question
export async function getAnalytics(pollId) {
  const rows = await db
    .select({
      questionId:   questions.id,
      questionText: questions.text,
      isMandatory:  questions.isMandatory,
      orderIndex:   questions.orderIndex,
      optionId:     options.id,
      optionText:   options.text,
      count:        sql`count(${answers.id})::int`,
    })
    .from(questions)
    .leftJoin(options,  eq(options.questionId,       questions.id))
    .leftJoin(answers,  eq(answers.selectedOptionId, options.id))
    .where(eq(questions.pollId, pollId))
    .groupBy(
      questions.id, questions.text, questions.isMandatory,
      questions.orderIndex, options.id, options.text
    )
    .orderBy(questions.orderIndex, options.orderIndex);

  const [{ total }] = await db
    .select({ total: sql`count(*)::int` })
    .from(responses)
    .where(eq(responses.pollId, pollId));

  // Shape into nested question → options structure
  const questionMap = new Map();
  for (const row of rows) {
    if (!questionMap.has(row.questionId)) {
      questionMap.set(row.questionId, {
        id:          row.questionId,
        text:        row.questionText,
        isMandatory: row.isMandatory,
        options:     [],
      });
    }
    if (row.optionId) {
      questionMap.get(row.questionId).options.push({
        id:    row.optionId,
        text:  row.optionText,
        count: row.count,
      });
    }
  }

  return { totalResponses: total, questions: [...questionMap.values()] };
}

const router = Router();

// Protected — creator only
router.get('/:id/analytics', requireSession, requirePollOwner, async (req, res) => {
  const stats = await getAnalytics(req.params.id);
  res.json(stats);
});

// Public — only after poll is published
router.get('/:slug/results', async (req, res) => {
  const [poll] = await db.select().from(polls).where(eq(polls.publicSlug, req.params.slug));
  if (!poll || !poll.isPublished) {
    return res.status(404).json({ error: 'Results not available' });
  }
  const stats = await getAnalytics(poll.id);
  res.json(stats);
});

export default router;
```

## WebSocket (Socket.io)

### Server setup — `server/socket/index.js`

```js
import { Server } from 'socket.io';

export function setupSocket(httpServer) {
  const io = new Server(httpServer, {
    cors: { origin: process.env.CLIENT_URL, credentials: true }
  });

  io.on('connection', (socket) => {
    socket.on('join_poll',  (pollId) => socket.join(pollId));
    socket.on('leave_poll', (pollId) => socket.leave(pollId));
  });

  return io;
}
```

### Client hook — `client/src/hooks/useSocket.js`

```js
import { useEffect, useRef } from 'react';
import { io } from 'socket.io-client';

export function useSocket(pollId, onUpdate) {
  const socketRef = useRef(null);

  useEffect(() => {
    if (!pollId) return;

    const socket = io(import.meta.env.VITE_API_URL, { withCredentials: true });
    socketRef.current = socket;

    socket.emit('join_poll', pollId);
    socket.on('live_update', onUpdate);

    return () => {
      socket.emit('leave_poll', pollId);
      socket.disconnect();
    };
  }, [pollId]);

  return socketRef;
}
```

## Poll Expiry Cron Job

**`server/jobs/expiryChecker.js`**

```js
import cron from 'node-cron';
import { db } from '../db/index.js';
import { polls } from '../db/schema.js';
import { and, eq, lte, isNotNull } from 'drizzle-orm';

export function startExpiryJob() {
  cron.schedule('* * * * *', async () => {
    await db
      .update(polls)
      .set({ isActive: false })
      .where(
        and(
          eq(polls.isActive, true),
          isNotNull(polls.expiresAt),
          lte(polls.expiresAt, new Date())
        )
      );
  });
}
```

Runs every minute. The response route also hard-checks `expiresAt` at request time to cover the gap between cron runs.

### Poll Builder — dynamic form state

```jsx
const [questions, setQuestions] = useState([
  { text: '', isMandatory: true, options: ['', ''] }
]);

const addQuestion = () =>
  setQuestions(qs => [...qs, { text: '', isMandatory: true, options: ['', ''] }]);

const addOption = (qi) =>
  setQuestions(qs => qs.map((q, i) =>
    i === qi ? { ...q, options: [...q.options, ''] } : q
  ));

const updateOption = (qi, oi, value) =>
  setQuestions(qs => qs.map((q, i) =>
    i === qi
      ? { ...q, options: q.options.map((o, j) => j === oi ? value : o) }
      : q
  ));

const removeOption = (qi, oi) =>
  setQuestions(qs => qs.map((q, i) =>
    i === qi
      ? { ...q, options: q.options.filter((_, j) => j !== oi) }
      : q
  ));
```

Validation before submit: each question needs text, at least 2 non-empty options, no duplicate option values.

## Implementation Order

### Phase 1 — Backend core
- Set up Express app + session middleware
- Drizzle schema + first migration (`npx drizzle-kit generate && npx drizzle-kit migrate`)
- OIDC discovery + `/auth/login` and `/auth/callback` routes
- `requireSession` + `requirePollOwner` middleware
- Poll CRUD routes with slug generation via `nanoid`

### Phase 2 — Response engine
- Submit response route with full validation chain (active → expiry → auth → duplicate → mandatory)
- Anonymous `sessionToken` handling via client `localStorage`
- `node-cron` expiry job

### Phase 3 — Analytics
- `getAnalytics()` helper with single SQL query
- `/api/polls/:id/analytics` (protected) and `/api/polls/:slug/results` (public after publish)
- Publish endpoint (`POST /api/polls/:id/publish`)

### Phase 4 — Frontend
- Vite project setup, Axios instance with `withCredentials: true`
- Auth flow (landing → `/auth/login` redirect → session check via `/api/me`)
- Dashboard (list polls, link to builder, delete)
- Poll builder (dynamic question + option form)
- Public poll form (answer + submit, duplicate detection via `localStorage` token)
- Results page (visible when `is_published = true`)

### Phase 5 — Real-time
- Socket.io server + room setup
- Emit `live_update` from response route after each save
- `useSocket` hook in client
- Analytics dashboard consumes live updates, Recharts re-renders on state change

## Key Design Decisions (Summary)

| Decision | Reason |
|---|---|
| OIDC `sub` as stable user key | Survives email changes; provider-agnostic |
| `public_slug` separate from UUID | Clean shareable URLs, hides internal IDs |
| Session cookie over stateless JWT | Simpler server-side revocation; works naturally with OIDC |
| Dual expiry check (cron + request-time) | Cron runs every minute so request-time check closes the race window |
| `session_token` in localStorage for anon | Prevents re-submission without storing user identity |
| Single analytics SQL query | One round-trip for all option counts; scales well |
| Socket.io rooms keyed by poll UUID | Efficient — only subscribers to that poll receive updates |
| Drizzle over Prisma | Lighter, closer to SQL, no binary engine, ESM-friendly |
| `"type": "module"` in server package.json | Consistent ESM `import/export` across all server files |
